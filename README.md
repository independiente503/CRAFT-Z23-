🤖 CRAFT-Z23

Autonomous VTuber AI Core (Secure & Real)

CRAFT-Z23 es un sistema real y funcional de VTuber autónomo basado en inteligencia artificial, con memoria persistente, personalidad evolutiva y una arquitectura de seguridad robusta. Este proyecto NO es un demo ni humo. Es una base técnica sólida, extensible y controlada.

____________________________________

🎯 OBJETIVO

Crear una entidad VTuber capaz de:

· Interactuar en tiempo real
· Mantener coherencia de personalidad
· Recordar interacciones pasadas
· Operar de forma autónoma
· Mantener seguridad y control humano

🔐 SEGURIDAD

CRAFT-Z23 incluye:

· Rate limiting contra spam
· Protección contra prompt injection
· Watchdog de estabilidad
· Arquitectura modular y auditable
· Separación clara entre lógica y LLM

No se permite:

· Autonomía sin control
· Ejecución de comandos del sistema
· Acceso a archivos arbitrarios
· Auto-modificación de código
